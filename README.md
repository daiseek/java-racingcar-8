# java-racingcar-precourse

## 기능 요구 사항
1. 횟수가 주어지며, 자동차 n대는 전진 혹은 정지를 할 수 있다.
- 사용자에게 횟수를 입력받는다.

2. 각 자동차에는 이름을 부여할 수 있다. 전진하는 자동차는 출력할 때 자동차 이름을 같이 출력한다.
3. 자동차 이름은 쉼표를 기준으로 구분하고 이름은 5자 이하여야 한다.
- 각 라운드(시도 횟수)마다 자동차가 움직인 결과를 표시해야 한다.
- 이때 1번 전진하면 하이픈(-) 1개를 이용해 표시한다.

4. 사용자는 몇 번 이동할 것인지 입력할 수 있다.

5. 전진하는 조건 : 0과 9 사이의 임의의 값을 구한 후 그 값이 4이상일 때
- 자동차마다 임의의 값을 구한다.
- 라운드마다 임의의 값을 구해야 한다.

6. 자동차 경주 게임을 완료한 후 누가 우승하였는지 알려주어야 한다. 우승자는 한 명일 수 있다.
7. 우승자가 여러 명일 경우 쉼표로 구분한다.
- 모든 라운드가 끝난 뒤 하이픈 개수가 제일 많은 자동차가 이긴다.
- 이때 동점자(하이픈 개수가 같은 차)가 존재하면 쉼표로 구분해 출력한다.

8. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션이 종료되어야 한다.


- 입력 요구 사항
1. 경주할 자동차의 이름을 쉼표로 구분지어 입력받음
2. 시도할 횟수(양의 정수)

- 출력 요구 사항
1. 차수별 실행 결과를 자동차 이름 별로 하이픈을 통해 알려줌
ex.
 ```java
 pobi : --
 woni : ----
 jun : ---
 ```

 2. 단독 혹은 공동 우승자 안내 문구
 ```java
 최종 우승자 : pobi
 ```

 ```java
 최종 우승자 : pobi, jun
 ```

- 실행 결과 예시
```java
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----

jun : ----

pobi : -----

최종 우승자 : pobi, jun
```

## 이외 요구 사항
1. JDK 21 버전을 사용
2. build.gradle 파일은 변경할 수 없다. 즉, 제공된 라이브러리 외에 외부 라이브러리는 사용하지 않는다.
3. 프로그램 종료시 System.exit()를 호출하지 않는다.
4. indent(들여쓰기) depth는 2까지 허용한다.
- indent depth는 함수 혹은 메서드를 분리하여 작성하면 줄일 수 있다.
5. 함수(메서드)는 한 가지의 작업만 하도록 작성해라.
6. JUnit5, AssertJ를 이용해 구현한 기능들이 잘 작동하는지 테스트 코드로 확인한다.
7. camp.nextstep.edu.missionutils에서 제공하는 Randoms 및 Console API를 사용하여 구현해야 한다.
   Random 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickNumberInRange()를 활용한다.
   사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.
